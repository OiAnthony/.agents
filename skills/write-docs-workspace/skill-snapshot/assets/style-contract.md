# 风格卡：〈名称，例如「DeepSeek 探索型」或「我的周报」〉

来源样例：〈1–3 篇链接或文件〉
样例用途：仅提取风格，不作为当前任务的事实来源。

| 项 | 描述 |
|---|---|
| 读者 | |
| 人称 | 「我们」/「我」/ 不出现人称；是否称呼读者 |
| 句长 | 大多数句子约 〈n〉 字；最长约 〈m〉 字；短句用在〈判断/转折〉 |
| 段落 | 每段约 〈n〉 句；段首句〈是结论/是场景〉 |
| 标题 | 判断句 / 名词短语；层级 |
| 证据 | 判断后通常跟〈数字/代码/链接/截图〉 |
| 格式 | 列表〈少/中/多〉，表格用于〈……〉，加粗〈几乎不用〉 |
| 术语 | 中英混排规则；首次出现的写法 |
| 语气 | 〈克制/直接/带个人判断〉；如何表达不确定（「我们推测」「尚未验证」） |
| 从不 | 〈例：从不用感叹号；从不在结尾总结；从不用某个黑话〉 |
