## `〈table_name〉`

一行代表〈一个……，不是……〉。

- **归属**：〈写入服务〉写，〈读取方〉读；Owner：〈人或团队〉
- **规模**：当前 〈N〉 行，日增 〈M〉，一年后预计 〈K〉
- **保留**：〈保留期、归档、删除策略〉
